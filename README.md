# 로또 분석 앱

저장한 번호를 로또 6/45의 역대 당첨 결과와 비교하는 iOS 앱이다. 조합 하나를 선택하면 번호별 출현 빈도, 가장 많이 일치한 과거 회차, 조합의 패턴을 페이지별로 확인할 수 있다. 랜덤 뽑기와 역대 통계 뽑기는 각각 독립된 메뉴로 제공할 계획이다.
