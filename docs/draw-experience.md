# 뽑기 화면과 연출

**디자인과 뽑는 순간이 이 앱의 핵심 경험이다.** 통계는 결과에 맥락을 붙이고, 다시 켜고 싶은 이유는 번호가 공개되는 순간과 결과의 완성도에서 만든다.

## 첫 시안 방향

밝고 선명한 컬러와 입체적인 공을 중심에 둔다. 라이트가 공 표면을 스치고, 배경은 읽기 쉬운 톤으로 정리한다. 결과 카드는 스크린샷으로 남기고 싶은 크기와 활자를 갖춘다. 구체적인 색과 모션은 실제 화면 시안에서 같이 검토한다.

## 뽑기 경험

1. 준비 화면에서는 고정 번호와 조합 수를 고르고, 화면 중심의 버튼으로 시작한다.
2. 랜덤은 탭과 동시에, 통계 뽑기는 유효한 응답을 받은 직후에 연출을 시작한다. 통계가 늦으면 준비 상태를 보여준다.
3. 추첨 공이 하나씩 앞으로 나오고 숫자가 선명해지는 순서로 여섯 번호를 공개한다. 고정 번호 표시와 공개 순서를 구분한다.
4. 마지막 공에서 조명과 짧은 피드백을 강조하고, 이후에는 결과 카드와 저장·분석·다시 뽑기 버튼에 시선을 모은다.
5. 사용자가 넘기기를 누르거나 동작 줄이기를 켜면 결과를 바로 읽을 수 있게 한다. 사운드와 햅틱은 설정에서 끌 수 있게 설계한다.

시작부터 결과까지 전체 화면 상태를 먼저 프로토타입으로 확인한다. 여러 조합을 뽑을 때는 하나씩 같은 연출을 길게 반복하는 대신 결과 카드로 빠르게 이동한다. 결과 번호의 검증과 렌더링을 분리해 애니메이션이 중단돼도 같은 조합이 남게 한다. VoiceOver에는 공개가 끝난 번호를 한 번에 읽을 수 있는 결과 레이블을 제공한다.
