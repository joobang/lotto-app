# 제품 계획

저장한 조합을 역대 당첨 번호와 비교하고, 랜덤 또는 역대 통계를 이용해 새 조합을 만드는 iPhone 앱이다. 자주 나왔던 번호나 과거에 비슷했던 회차를 직접 확인하는 데 초점을 둔다.

## 첫 버전 메뉴

| 메뉴 | 첫 화면 | 주요 행동 |
| --- | --- | --- |
| 내 번호 | 기기에 저장한 조합 목록 | 직접 등록, 이름 변경, 번호 수정, 삭제, 조합 분석 열기 |
| 랜덤 뽑기 | 고정 번호 선택, 뽑을 조합 수 | 1·3·5조합 중 선택해 균등 랜덤 생성, 다시 뽑기, 개별 결과 저장·분석 |
| 역대 통계 뽑기 | 역대 빈도와 역대 구성 중 기준 선택 | 고정 번호와 조합 수를 선택해 생성, 결과별 적용 기준 확인, 저장·분석 |
| 역대 통계 | 마지막 확인 회차와 1~45번 전체 빈도 | 출현 횟수순 또는 번호순 정렬, 번호 상세, 회차별 당첨번호 보기 |

별도 메뉴인 **역대 통계**에서는 내 조합을 저장하기 전에도 전체 분포를 볼 수 있다. **역대 통계 뽑기**에서는 같은 데이터를 조합 생성에 사용하고, 결과마다 적용한 기준과 반영 회차를 보여준다.

## 내 번호를 기준으로 보는 네 페이지

1. 1~45에서 서로 다른 번호 6개를 선택하고 저장한다. 이름을 생략하면 기본 이름으로 저장한다.
2. 예시 조합 `3, 11, 19, 24, 32, 41`을 누르면 상단에 번호와 집계 범위를 표시하고 요약 페이지를 연다.
3. 좌우로 넘기거나 상단 탭을 눌러 네 페이지를 이동한다. 탭을 이동하는 동안 같은 번호 조합이 선택된 상태를 유지한다.
4. 유사 회차를 누르면 추첨일·본번호·보너스와 내 번호를 함께 볼 수 있다.

| 페이지 | 보여줄 내용 |
| --- | --- |
| 요약 | 역대 최대 일치 개수, 완전 일치 횟수, 본번호가 정확히 3·4·5·6개 일치한 회차 수 |
| 번호별 | 선택 번호 6개의 본번호 출현 횟수와 비율, 마지막 등장 회차, 전체 45개 중 출현 순위 |
| 유사 회차 | 많이 겹친 회차부터 표시하고 동률이면 최신 회차를 우선한다. 겹친 본번호와 보너스 일치는 구분한다. |
| 패턴 | 선택한 15개 번호 쌍의 동시 출현, 홀짝 구성, 번호대 분포, 합계와 역대 분포의 비교 |

좌우 이동 없이 탭만으로도 네 페이지를 열 수 있다. 화면 읽기 기능은 선택된 탭과 공 번호를 읽을 수 있어야 한다. 일치 회차가 없으면 0회, 사용 가능한 이력이 없으면 통계 준비 상태를 표시한다.

## 두 뽑기 기능의 공통 동작

- 고정 번호는 0~5개, 뽑을 조합 수는 1·3·5개이며 기본값은 1개다. 결과마다 서로 다른 번호 6개를 오름차순으로 표시한다.
- 한 번에 받은 조합 중 원하는 것만 저장한다. 저장하지 않고 바로 분석할 수 있다. 같은 번호의 조합을 이미 저장했다면 기존 조합을 열 수 있게 표시한다.
- 생성 결과를 저장하고 다시 뽑을 때도 선택한 고정 번호는 유지한다. 집중 상태나 네트워크 전환으로 같은 응답이 두 번 표시되지 않도록 새 요청과 이전 응답을 구분한다.
- 랜덤은 항상 기기에서 동작한다. 통계 뽑기는 서버의 검증 이력을 사용한다. 통계 생성이 일시적으로 실패하면 다시 시도할 수 있고, 이미 생성한 결과 카드는 유지한다.

## 역대 통계 뽑기 기준

| 기준 | 생성 방식 | 결과 설명 |
| --- | --- | --- |
| 역대 출현 빈도 | 본번호 출현이 많았던 번호에 더 큰 추출 가중치를 적용한다. 고정 번호를 포함해 여섯 수를 채운다. | 선택된 각 번호의 실제 출현 횟수와 표본 범위 |
| 역대 조합 구성 | 실제 이력에서 자주 관측된 홀수 개수·번호대 조합 중 고정 번호와 양립하는 구성을 선택한다. | 사용한 홀짝·번호대 구성과 같은 구성이 나왔던 횟수 |

전부 **1회부터 마지막으로 검증한 회차까지** 집계한다. 추천은 과거 데이터에 따라 조합을 만드는 기능이다. 공정 추첨에서 각 6개 조합이 뽑힐 확률은 같다.

## 첫 버전 요구사항

| ID | 완료 조건 |
| --- | --- |
| LOTTO-01 | 1회부터 확인된 최신 회차까지 검증한 이력을 읽을 수 있고, 마지막 회차를 표시한다. |
| LOTTO-02 | 여러 조합을 기기에 저장하고 이름·번호를 수정하거나 삭제할 수 있다. 앱 재실행 뒤에도 복원된다. |
| LOTTO-03 | 선택한 조합의 요약·번호별·유사 회차·패턴을 페이지별로 탐색한다. |
| LOTTO-04 | 랜덤 뽑기와 역대 통계 뽑기를 별도로 열 수 있다. 통계 뽑기에서 두 생성 기준과 실제 근거를 확인하고 결과를 저장·분석할 수 있다. |
| LOTTO-05 | 새 추첨 결과를 검증 후 반영하고, 갱신이 실패하면 마지막 정상 이력을 제공한다. |
| LOTTO-06 | 저장한 조합 없이도 전체 45개 번호의 역대 통계와 회차별 당첨 결과를 조회할 수 있다. |

구매, 결제, 로그인, 서버 조합 동기화, 알림은 첫 버전의 범위 밖이다. 작업 순서와 완료 확인은 [구현 계획](implementation-plan.md)을 따른다.
