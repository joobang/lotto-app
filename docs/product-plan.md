# 제품 계획

## 사용자 흐름

1. 홈에서 1~45 중 서로 다른 번호 6개를 고르고 이름을 붙여 저장한다. 랜덤으로 만든 조합도 같은 목록에 저장할 수 있다.
2. 저장 조합을 탭하면 해당 조합의 분석 화면이 열린다. 예시 조합은 `3, 11, 19, 24, 32, 41`이다.
3. 분석 상단에 선택한 여섯 번호와 마지막 검증 회차를 고정한다. 좌우로 넘기거나 탭을 눌러 페이지를 이동할 수 있다.
4. 유사 회차를 누르면 해당 회차의 당첨번호, 추첨일, 일치한 번호와 보너스를 상세에서 비교할 수 있다.

## 저장 조합의 분석 페이지

| 페이지 | 확인할 내용 |
| --- | --- |
| 요약 | 이 조합의 역대 최대 일치 개수, 완전 일치 횟수, 3·4·5·6개 일치 횟수 |
| 번호별 통계 | 선택한 번호마다 역대 본번호 출현 횟수·비율, 마지막 등장 회차, 번호 45개의 순위에서 해당 번호의 위치 |
| 유사 회차 | 본번호 일치 개수가 높은 순으로 회차 나열. 동률은 최신 회차부터 표시. 일치 번호와 보너스 일치는 따로 표시 |
| 조합 패턴 | 선택한 15개 번호 쌍이 함께 나온 횟수, 홀짝 구성, 번호대별 분포, 번호 합계와 역대 분포에서의 위치 |

왼쪽과 오른쪽 페이지 이동은 탭으로도 가능하게 하고, 화면 읽기 기능에서 현재 페이지 이름과 조합을 알 수 있게 한다. 결과가 0이면 0을 표시하고, 분석용 데이터가 없을 때는 마지막 확인 회차와 불러오기 상태를 보여준다.

## 생성과 추천

- 랜덤은 서로 다른 번호 6개를 균등하게 뽑는다.
- 역대 출현 빈도를 활용한 조합 추천과 홀짝·번호대를 고려한 조합 추천을 제공한다. 한 조합마다 적용한 기준을 보여준다.
- 원하는 번호를 일부 고정하고 나머지를 생성할 수 있다. 생성된 조합은 수정·저장·분석 흐름에 연결한다.
- 통계 비교에 쓰는 범위는 1회부터 마지막으로 확인한 회차까지다. 추천 설명은 적용한 조합 기준과 과거 관측 결과를 전달한다.

## 첫 버전 요구사항

| ID | 완료 조건 |
| --- | --- |
| LOTTO-01 | 1회부터 확인된 최신 회차까지 검증한 이력을 읽을 수 있고, 마지막 회차를 표시한다. |
| LOTTO-02 | 여러 조합을 기기에 저장하고 이름을 바꾸거나 삭제할 수 있다. 앱 재실행 뒤에도 복원된다. |
| LOTTO-03 | 저장한 조합에서 요약·번호별 통계·유사 회차·조합 패턴을 페이지별로 탐색할 수 있다. |
| LOTTO-04 | 랜덤과 두 가지 통계 기반 생성 방식을 제공하며 조합을 저장해 분석할 수 있다. |
| LOTTO-05 | 새 추첨 결과를 주기적으로 반영하고, 갱신이 실패하면 마지막 정상 이력을 제공한다. |

## 구현 순서

1. 전체 이력 확보 및 원본 검증, 최신 회차 갱신 경로 준비
2. 유사 회차와 번호별 집계 계산, 검증용 API 연결
3. SwiftUI 저장 조합 목록과 분석 페이지 구현
4. 랜덤·통계 생성과 기준 설명 구현, 실기기 및 새 회차 갱신 확인
