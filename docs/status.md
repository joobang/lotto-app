# 개발 상태와 인계

## 현재 상태

**1단계 추첨 이력 적재와 조회 구현을 로컬에서 검증했다.** 실제 1~1251회 스냅샷이 있고, 일회용 PostgreSQL에서 전체 적재·재시도·새 회차 검증·조회 API를 확인했다. 운영 적재나 배포 시 적용할 범위는 [LOTTO-01 기록](tasks/LOTTO-01.md)에 있다.

- 랜덤 뽑기와 역대 통계 뽑기는 각각 독립 메뉴다. 역대 통계 조회도 별도 화면이다.
- 저장한 조합에서는 요약·번호별·유사 회차·패턴 네 페이지를 이동한다.
- [뽑기 디자인과 연출](draw-experience.md)을 핵심 경험으로 확정했다. 화면 시안과 모션 구현은 후속이다.

## 다음 작업

[구현 계획의 단계 2](implementation-plan.md)에서 역대 분석 계산을 시작한다. iOS의 첫 시각 검토는 뽑기 준비, 번호가 순서대로 나오는 장면, 결과 카드를 연결한 시안이다.
