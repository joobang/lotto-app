# 개발 상태와 인계

## 현재 상태

제품 계획과 AI 공통 작업 규칙을 마련했다. 실제 iOS 구현, 공유 백엔드 변경, 운영 데이터 적재, 서비스 배포는 이후 구현 작업에서 진행한다.

- 첫 목표는 LOTTO-01의 전체 회차 초기 적재다. 공개 후보 자료의 회차 연속성 및 출처 대조 기록은 [데이터 설계](architecture.md)에 있다.
- 분석 화면은 선택한 저장 조합을 유지하며 네 페이지를 탐색하는 흐름으로 정했다.
- 제품 문서와 API 계약은 이 레포에서 관리한다.

## 다음 작업

검증 가능한 전체 이력 스냅샷을 준비하고 날짜·회차·번호·보너스 정합성 검사를 만든다. 공유 백엔드에 연결하기 전에 가상 데이터로 분석 계산을 검증한다.
