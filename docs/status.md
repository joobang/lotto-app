# 개발 상태와 인계

## 현재 상태

**첫 iPhone 버전을 구현했다.** 공을 당겨 발사해 여섯 번호를 빠르게 공개하고, 저장한 조합으로 역대 회차를 비교할 수 있다. 45개 번호 빈도와 역대 구성에 따른 패턴 뽑기는 역대 통계 탭에 있다. [첫 버전 작업 기록](tasks/LOTTO-02-04-preview.md)

- 비교 화면은 요약·닮은 회차·번호별·번호 쌍을 제공한다. 닮은 회차는 두 줄의 번호를 나란히 보여주고, 일치한 본번호를 표시한다.
- 발사대의 공을 아래로 끌면 충전되고, 충분히 당겨 놓으면 그 공이 소용돌이로 들어가 번호 공 여섯 개를 차례로 공개한다. 탭 대안과 동작 줄이기에서도 결과에 접근할 수 있다. [뽑기 디자인과 연출](draw-experience.md) · [번호 공개 작업 기록](tasks/LOTTO-04-pull-launch.md)
- 앱은 로컬 저장과 내장 1~1251회 이력으로 동작한다. 2단계 백엔드 통계·분석 API는 별도로 로컬에서 검증했다. [2단계 작업 기록](tasks/LOTTO-03-06.md) · [1단계 적재 기록](tasks/LOTTO-01.md)
