# 개발 상태와 인계

## 현재 상태

**계획 작성 완료. 구현 착수 대기.** 제품 메뉴·화면 이동, 역대 데이터 기준, API 계약, 구현 순서와 완료 조건을 정리했다.

- 랜덤 뽑기와 역대 통계 뽑기는 각각 독립 메뉴다. 역대 통계 조회도 별도 화면이다.
- 저장한 조합에서는 요약·번호별·유사 회차·패턴 네 페이지를 이동한다.
- 이력은 1회부터 마지막으로 검증한 회차까지 사용한다. 운영 적재 범위와 원본 대조 결과는 구현 시 기록한다.
- iOS 앱·공유 백엔드 로또 모듈·운영 데이터 적재·배포는 구현 단계에 속한다.
