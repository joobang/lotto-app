# 개발 상태와 인계

## 현재 상태

**2단계 역대 통계와 조합 분석 API를 로컬에서 검증했다.** 실제 1~1251회 이력에서 45개 번호 통계, 일치 개수 분포, 유사 회차, 조합 패턴 응답이 별도 계산과 일치했다. [2단계 작업 기록](tasks/LOTTO-03-06.md) · [1단계 적재 기록](tasks/LOTTO-01.md)

- 랜덤 뽑기와 역대 통계 뽑기는 각각 독립 메뉴다. 역대 통계 조회도 별도 화면이다.
- 저장한 조합에서는 요약·번호별·유사 회차·패턴 네 페이지를 이동한다.
- [뽑기 디자인과 연출](draw-experience.md)을 핵심 경험으로 확정했다. 화면 시안과 모션 구현은 후속이다.
