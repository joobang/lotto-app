# 개발 상태와 인계

## 현재 상태

**첫 iPhone 버전을 구현했다.** 한 번 탭으로 뽑기 카드를 빠르게 펼치고, 저장한 조합으로 역대 회차를 비교할 수 있다. 45개 번호 빈도와 역대 구성에 따른 패턴 뽑기는 역대 통계 탭에 있다. [첫 버전 작업 기록](tasks/LOTTO-02-04-preview.md)

- 비교 화면은 요약·닮은 회차·번호별·번호 쌍을 제공한다. 닮은 회차는 두 줄의 번호를 나란히 보여주고, 일치한 본번호를 표시한다.
- 게임형 컷신은 프리즘이 열리면서 두 줄에 번호 카드 여섯 장을 차례로 배치하고 마지막에 빛을 퍼뜨린다. 동작 줄이기에서는 결과를 즉시 보여준다. [뽑기 디자인과 연출](draw-experience.md) · [번호 공개 작업 기록](tasks/LOTTO-04-reward-reveal.md)
- 앱은 로컬 저장과 내장 1~1251회 이력으로 동작한다. 2단계 백엔드 통계·분석 API는 별도로 로컬에서 검증했다. [2단계 작업 기록](tasks/LOTTO-03-06.md) · [1단계 적재 기록](tasks/LOTTO-01.md)
