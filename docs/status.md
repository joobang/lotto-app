# 개발 상태와 인계

## 현재 상태

**첫 iPhone 버전을 구현했다.** 뽑기에서 한 번에 여섯 번호를 보고, 저장한 조합으로 역대 회차를 비교할 수 있다. 45개 번호의 출현 횟수와 이력을 활용한 빈도 뽑기는 역대 통계 탭에 있다. [첫 버전 작업 기록](tasks/LOTTO-02-04-preview.md)

- 비교 화면은 요약·닮은 회차·번호별·번호 쌍을 제공한다. 닮은 회차는 두 줄의 번호를 나란히 보여주고, 일치한 본번호를 표시한다.
- 앱의 첫 시각안은 밝은 바탕, 보라색 뽑기 무대, 라임 버튼, 짧은 빛 효과를 적용했다. [뽑기 디자인과 연출](draw-experience.md)
- 앱은 로컬 저장과 내장 1~1251회 이력으로 동작한다. 2단계 백엔드 통계·분석 API는 별도로 로컬에서 검증했다. [2단계 작업 기록](tasks/LOTTO-03-06.md) · [1단계 적재 기록](tasks/LOTTO-01.md)
