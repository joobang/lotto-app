# LOTTO-04·06 · 뽑기 컷신과 역대 패턴

기준은 `f87ea04`다. 전체 화면 컷신에서도 첫 프레임에 여섯 번호를 표시하고, 효과가 끝나면 같은 조합의 저장과 비교로 돌아간다. 동작 줄이기에서는 즉시 결과를 표시한다.

역대 패턴에서 홀짝, 합계 구간, 번호대 수, 연속번호를 집계한다. 패턴 뽑기는 역대 구성의 출현 횟수를 이용하고 45개 개별 번호 빈도를 조회에 유지한다. 예측 성능은 과거 구간에서 선택한 조합을 별도의 이후 구간에 적용해 확인한다.

실패 사례는 숫자 순차 표시, 컷신이 끝난 뒤 다른 번호가 나타남, 연속 재실행에서 이전 효과가 새 결과를 지움, 본번호 중복, 빈 이력, 드문 패턴의 생성 지연이다.

## 분석과 구현

본번호의 홀수 개수, 30점 단위 합계 구간, 사용한 번호대 개수, 연속번호 포함 여부의 결합 빈도를 집계했다. 관측의 1% 이상에 해당하는 구성 가운데 실제 출현 횟수에 비례해 하나를 선택한다. 1~45에서 중복 없이 균등 추출한 조합을 선택된 구성과 비교하고, 일치하면 결과와 회차 수를 표시한다. 생성 시도 4,096회를 넘으면 재시도 안내를 표시한다. 이 과정은 특정 번호의 가중치를 변경하지 않는다.

| 패턴 | 관측 1~1251회 | 균등 추첨 기준 |
| --- | --- | --- |
| 홀짝 3:3 | 416회 · 33.25% | 33.48% |
| 합계 121~150 | 467회 · 37.33% | 37.40% |
| 4개 번호대에 분포 | 660회 · 52.76% | 51.69% |
| 연속번호 포함 | 649회 · 51.88% | 52.87% |

1~1000회 빈도로 번호별 가중치를 만들고 1001~1251회를 별도로 평가했다. 기존 빈도 가중치의 가중 비복원 추출을 고정 시드로 20,000회 재현한 평균 일치 수는 0.799개였다. 빈도 상위 6개를 고정하면 0.801개였고, 균등 추첨 기대값은 0.800개다. 단일 홀드아웃 결과의 반올림된 평균이며 예측 우위의 근거로 사용하지 않는다.

## 실행 결과

- `python3 scripts/check_draw_patterns.py`에서 관측 건수, 조합론 기준값, 마지막 251회 홀드아웃 비교를 재현했다.
- 별도 Swift 검사에서 무작위와 패턴 생성 각각 2,000건, 선택 형태의 재계산과 관측 건수, 빈 이력 반환을 확인했다.
- iPhone 17 Pro 시뮬레이터 `xcodebuild test`에서 랜덤과 패턴 결과의 숫자 6개, 저장 복원, 역대 비교, 역대 패턴 분포 진입을 확인했다. 시뮬레이터 화면을 녹화했다.
- `xcodebuild -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build`를 실행했다. 실기기 설치, 햅틱, 동작 줄이기 설정의 실제 동작은 확인 전이다.
