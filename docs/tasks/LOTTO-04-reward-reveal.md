# LOTTO-04 · 게임형 번호 공개

기준 커밋은 `a500fad`다. 사용자 피드백에 따라 여섯 번호를 빠르게 순차 공개한다. 첫 카드와 마지막 카드 사이를 짧게 유지하고 마지막 착지 뒤 결과를 읽을 시간을 둔다. 랜덤과 패턴 뽑기가 같은 연출을 사용한다.

확인할 실패 사례는 번호 누락·중복 표시, 컷신과 저장 카드 번호 불일치, 앱에서 빠르게 재추첨할 때 이전 컷신이 남는 경우, 번호 가독성, 작은 화면의 카드 잘림, 동작 줄이기에서의 결과 접근이다.

## 연출과 검증

- 탭 뒤 80ms에 첫 카드 진입을 시작하고 57ms 간격으로 다음 카드를 공개하도록 설정했다. 여섯 번째 카드 진입은 365ms, 배치 완료는 약 470ms다. 컷신은 1.43초 뒤 끝난다. 기준 시점은 화면 연출 코드의 설정값이다.
- 프리즘, 색이 다른 카드 6장, 착지 파편, 카드 위 반사광, 마지막 금빛 파동을 쓴다. 애니메이션 진행과 관계없이 실제 뽑기 결과는 같은 여섯 번호다. 동작 줄이기에서는 컷신 없이 결과를 보여준다.
- iPhone 17 Pro 시뮬레이터에서 랜덤·패턴 뽑기 결과 여섯 번호, 저장 및 재실행 복원, 분석 진입을 확인하고 컷신을 녹화했다.
- `xcodebuild -project ios/Lotto.xcodeproj -scheme Lotto -configuration Debug -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build`가 통과했다. 실제 기기의 햅틱, 접근성 설정, 프레임 속도는 확인 전이다.
