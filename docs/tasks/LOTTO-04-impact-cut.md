# LOTTO-04 · 발사와 충돌 컷 재구성

기준 커밋은 `4e3e8bb`다. Cobalt Pull 실행 검토에서 확인한 터널 가속, 짧은 충돌 정지, 깊이가 다른 번호 공 분출을 기존 네이티브 연출에 적용한다. 코발트 장치와 법랑 숫자 면을 사용한다.

짧은 드래그 취소, 랜덤 및 패턴 발사, 공 번호와 결과 카드 일치, 작은 화면의 번호 잘림, 충돌 시 가독성과 효과음·햅틱 타이밍을 확인한다.

## 연출

- 장치 앞에서 카메라가 약 270ms 동안 좁은 공간으로 가속하며 화각이 48°에서 80°까지 커진다. 공간에 배치한 코발트와 골드 선이 거리감을 만든다.
- 충돌 지점에서 카메라와 발사 공을 55ms 유지한다. 중심 플레어와 충격파를 겹치고, 카메라가 되받아 물러나면서 조리개를 연다.
- 약 360ms부터 88ms 간격으로 번호 공을 발사한다. 각 공의 깊이, 회전 시작 각도, 착지 경로를 달리한다. 효과음과 착지 햅틱은 같은 순서와 타이밍으로 호출한다.
- 첫 녹화에서 카메라 기울기가 프레임마다 누적돼 정렬 뒤에도 구도가 틀어졌다. 카메라의 위 방향을 매 프레임 절대 각도로 지정해 회전이 끝난 뒤 수평을 복원했다.

## 확인 결과

- iPhone 17 Pro 시뮬레이터에서 `xcodebuild test` 통과. 드래그 취소·발사, 랜덤과 패턴 뽑기, 탭 대안, 저장 재실행 및 역대 비교를 확인했다.
- 최종 녹화의 컷신과 결과 카드에서 같은 번호 05, 14, 36, 37, 43, 45를 확인했다. 효과음은 녹화에 앱의 WAV 파일을 맞춰 넣었다.
- `xcodebuild -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build` 통과. 실기기 프레임과 햅틱의 체감은 확인 전이다.
