# LOTTO-04 · 뽑기 시각 연출 재설계

기준 커밋은 `7b547dc`다. 사용자가 검토한 당겨 놓기 조작은 유지한다. 대기 화면과 컷신이 같은 코발트 합금 추첨 장치를 사용하고, 카메라 이동, 조리개 개방, 번호 공의 깊이와 표면 번호를 3D로 렌더링한다. 기본 앱 색과 결과 카드도 같은 재질에 맞춘다.

확인할 경계는 짧은 드래그, 재발사, 화면 비율별 번호 잘림, 자릿수 가독성, 컷신과 저장 번호 일치, 시뮬레이터 및 기기 빌드다.

## 구현과 확인

- 발사대와 전체 화면 컷신은 같은 SceneKit 장치 모델을 재사용한다. 튜브와 조리개 형상, 조명, 반사 환경은 코드에서 생성한다. 이전 배경 JPEG 두 개는 새 앱 번들의 리소스에서 제외했다.
- 주 카메라가 장치로 접근한 뒤 뒤로 이동하며, 조리개 조각이 순차 개방되고 색이 있는 구체가 서로 다른 깊이에서 나온다. 숫자는 구체의 곡면에 적용한 인쇄면으로 표시한다. 후반 카메라 거리와 소재 채도를 조정해 iPhone 17 Pro 캡처에서 여섯 공의 전체 윤곽과 숫자를 확인했다.
- 이전 발사 효과음은 새 장면과 함께 재사용한다. 미리보기 영상은 실제 시뮬레이터 녹화에 앱 효과음을 맞춰 편집했다.
- `xcodebuild test`에서 짧은 드래그 취소, 랜덤·패턴 발사, 탭 대안, 여섯 번호 출력, 저장 재실행과 회차 비교가 통과했다.
- `xcodebuild -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build`가 통과했다. 실기기 프레임 속도, 발열, 햅틱은 실제 기기에서 확인할 항목이다.
