# LOTTO-02·03·04·06 · 첫 iPhone 버전

- 기준은 `b7671d7`, 작업 브랜치는 `codex/lotto-iphone-preview`다.
- 번호 여섯 개가 같은 화면 갱신에서 드러나는 뽑기로 시작한다. 밝은 바탕에 보라색 무대, 라임 버튼, 유리 공을 사용한다. 빛 효과는 번호 공개와 별도로 약 240ms 동안 재생한다.
- 조합을 직접 입력하거나 뽑기에서 저장한다. 화면을 다시 열어도 저장이 유지돼야 한다. 역대 비교는 요약, 닮은 회차, 번호별 횟수, 함께 나온 번호 쌍을 가로로 넘겨 확인한다.
- 내장 이력 1~1251회로 45개 번호 빈도를 표시한다. 빈도에 가중치를 준 조합 뽑기를 제공한다. 데이터 출처와 확인 범위는 [초기 이력 기록](LOTTO-01.md)에 남겼다.
- 확인할 실패 사례는 중복 번호, 이미 저장한 조합, 앱 재실행, 본번호와 보너스의 혼합, 최대 일치 수가 같을 때 회차 정렬, 내장 이력 누락이다.
- 서버에는 연결하지 않는다. 이번 검토 범위는 첫 시각안, 기기 내 저장, 기본 비교와 빈도 뽑기다. 실기기 햅틱과 최신 회차 동기화가 남아 있다.

## 검증 결과

- `xcodebuild -project ios/Lotto.xcodeproj -scheme Lotto -destination 'id=866174BE-CB3E-44E6-BED4-2AD8D82A460B' -parallel-testing-enabled NO CODE_SIGNING_ALLOWED=NO test`에서 iPhone 17 Pro 시뮬레이터 UI 테스트 1건이 통과했다. 뽑기 결과 표시, 조합 저장 및 앱 재실행 복원, 직접 입력, 분석 탭, 통계 뽑기를 실행했고 5개 화면을 캡처했다.
- 별도 Python 계산으로 1~1251회 연속성, 본번호·보너스 유효성, 45개 번호의 총 출현 횟수 7,506을 확인했다. 예시 조합의 본번호 4개 일치 이력은 203회와 268회였다.
- 실제 iPhone의 첫 입력부터 표시까지 걸린 시간, 햅틱, 접근성 설정과 편집·삭제는 이번 실행에서 확인하지 않았다.
